📌 使用方法：

  1. 点击上传图片或文件夹，或拖拽图片到上传区
  2. 点击 "确认上传" 自动按文件名中的数字排序
  3. 也可拖拽列表手动调整顺序 / 点击 ✕ 删除
  4. 点击 "转换" 预览（根据当前模式）
  5. 导出为 PDF 或 Word（所有图片 按顺序导出）

💡 文件名数字识别：支持 _数字、(数字)、（数字） 等格式

📌 温馨提示：

  1. 请只点击一次确认上传按钮，不要点击多次
  2. 生成PDF文件时，时间较久，需要耐心等待，请不要多次点击生成PDF文件按钮
